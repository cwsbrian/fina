My recommendation

Option A를 메인으로, 그 안에서 B·C의 좋은 부분을 흡수

일상 사용은 90%가 "이번 달 / 지난달" 정도라서 월 스테퍼(A)가 가장 빠르고 친근해요. 가운데 라벨 ("May 2025")을 탭했을 때 열리는 picker 시트 안에 B의 미니 막대그래프 월 리스트를 넣고, 그 시트 하단에 "Custom range…" 버튼으로 C의 캘린더 레인지 픽커를 숨겨두는 방식이에요.

이렇게 두면 일반 케이스는 한 탭으로, 비교적 흔한 "지난 3개월"은 시트의 preset 한 번 더 탭으로, 파워 유저의 "5월 12일–6월 8일" 같은 임의 구간은 Custom으로 — 헤더가 가벼우면서도 깊이가 살아남아요.
