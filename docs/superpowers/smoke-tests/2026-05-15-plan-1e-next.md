# Plan 1E-next — Smoke Test

End-to-end manual verification for the implementation in
`docs/superpowers/plans/2026-05-15-plan-1e-next.md`. Covers the seven new
read-only chat tools and the shared `periods.ts` helper.

All commands run from the repo root unless noted.

---

## Environment

- Postgres dev container on **5433** (`fina-postgres-dev`).
- API runs on **4000**, web on **3100** (Plan 2 convention).
- Dev mode skips Resend / Plaid sandbox unless their keys are set.
- This plan requires `GEMINI_API_KEY` (or `GOOGLE_API_KEY`) to exercise the chat
  loop. Without it, chat tool dispatch still works but the LLM call fails.
- Gemini free-tier limits for `gemini-2.5-flash-lite` (as of 2026-05): **10
  requests/minute** AND **20 requests/day**. Each chat turn issues 2 LLM calls
  (tool plan + final synthesis), so the full 7-tool walkthrough costs ~14
  requests in one sitting. If you hit `chat_provider_error` with a 429, wait
  the suggested retry window. A paid-tier key removes both caps.

## 4. Exercise each tool via chat (Terminal 2)

Helper to send a prompt:

```bash
chat() {
  local prompt="$1"
  curl -sS -b /tmp/fina-cookies.txt -X POST \
    "http://localhost:4000/workspaces/$WS_ID/chat/message" \
    -H "content-type: application/json" \
    -H "x-workspace-id: $WS_ID" \
    -d "{\"text\":$(jq -nR --arg t "$prompt" '$t')}" | jq '{tools:[.toolCalls[].toolName], text:.assistantMessage.blocks[0].markdown}'
}
```

Run each prompt and confirm the `tools` array contains the expected name.

### 4.1 `listAccounts`

```bash
chat "Which bank accounts do I have connected and what are their balances?"
```

**Expect:** `tools` contains `"listAccounts"`. Response mentions Chequing.

### 4.2 `getTransactionDetails`

```bash
chat "Show me the full details for transaction tx-smoke-food-1"
```

**Expect:** `tools` contains `"getTransactionDetails"`. Response mentions
Subway / Food / $30.

### 4.3 `findUncategorizedTransactions`

```bash

```

**Expect:** `tools` contains `"findUncategorizedTransactions"`. Response
mentions `Random Store` (the only uncategorized non-Netflix tx — Netflix
seeds are uncategorized too, so any subset is acceptable).

### 4.4 `getCategoryBreakdown`


**Expect:** `tools` contains `"getCategoryBreakdown"`. Response shows Food

**Expect:** `tools` contains `"compareSpendingPeriods"`. Response shows that

### 4.6 `detectRecurringMerchants`
