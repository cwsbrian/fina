# Fina 1.16

Date: 2026-08-10

## App Store — What’s New

- Chat now opens directly at your latest messages without a long scroll.
- Older conversation history loads smoothly as you scroll upward.
- Morning Briefs are skipped when a workspace has no transactions or no recent financial activity.
- Improved AI response speed and reliability.

## User-Facing Changes

- Chat initially loads only the latest messages and fetches older history in pages when you scroll upward.
- Workspaces without transactions or recent activity no longer generate or send a Morning Brief.
- Chat and Morning Brief generation now use the more efficient GPT-5 nano model with stable prompt caching.

## TestFlight — What to Test

- Open a long conversation and confirm the newest message is visible immediately without a top-to-bottom scroll animation.
- Scroll upward and confirm older messages load without moving the currently visible message.
- Send a new message after loading older history and confirm the conversation returns to the latest reply.
- Confirm inactive workspaces do not receive a Morning Brief.
