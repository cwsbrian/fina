# Fina 1.11

Date: 2026-07-27

## App Store — What’s New

- Made sign-in sessions more reliable and clarified which features are included in the Free plan.
- Improved Pro conversations with one continuous chat per workspace and more context-aware Morning Briefs.
- Prevented duplicate transactions when reconnecting a previously linked financial institution.
- Displayed subscription prices using the customer’s local App Store or Google Play storefront.
- Fixed the extra space between the chat composer and the keyboard.

## User-Facing Changes

- Free plan
  - Chat, Goals, and Morning Brief now show an upgrade screen before an unavailable feature can be used.
  - LLM-powered features no longer run for Free accounts.
  - Linked Plaid items are removed after a downgrade while imported transaction history is preserved.
- Pro plan
  - Each workspace now has one continuous conversation instead of multiple selectable threads.
  - Morning Brief uses recent workspace conversation context and previous briefs to provide more relevant guidance.
  - Long conversations are trimmed to a recent context window and use a stable prompt prefix for provider caching.
- Plaid
  - Reconnecting a previously removed institution preserves transaction history without creating duplicates.
- Billing
  - Plan prices come from StoreKit or Google Play and respect the customer’s storefront and currency.
- Reliability and polish
  - Sign-in sessions now use a longer sliding refresh window.
  - Removed the oversized keyboard gap in Chat.

## TestFlight — What to Test

- Switch an account between Free and Pro and verify Chat, Goals, and Morning Brief availability.
- On Pro, verify each workspace opens its single ongoing conversation and Morning Brief reflects prior discussion.
- Reconnect a previously linked Plaid institution and confirm historical transactions are not duplicated.
- Confirm the Plan screen shows the localized storefront price on a development or TestFlight build.
- Open the Chat keyboard and confirm the composer remains directly above it.
