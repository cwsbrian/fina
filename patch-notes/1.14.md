# Fina 1.14

Date: 2026-08-04

## App Store — What’s New

- Filter Activity by transaction type, date, and category from one place.
- Fixed an issue that could save a monthly budget to the wrong month near a timezone month boundary.
- Improved consistency between the Budget screen, Home, and chat when determining the current month.

## User-Facing Changes

- Unified Activity filters
  - Filter transactions by All, Expenses, or Income.
  - Transaction type, date, and category filters are organized in a dedicated filter screen with focused selection sheets.
  - Active filters appear as removable badges directly below the Activity header.
- Timezone-aware monthly budgets
  - The Budget screen now saves changes to the same current month returned by the server.
  - Budget actions in chat now use the user's timezone when resolving this month, last month, and next month.
  - Home, chat, and the Budget screen now agree on the active month around UTC/local month boundaries.

## TestFlight — What to Test

- Confirm the Filters screen opens with a standard side navigation transition, then try Expenses and Income separately.
- Combine a transaction type with a date preset or custom range and one or more categories, then confirm each active filter appears as a removable header badge.
- Remove individual badges with their × buttons and confirm only that filter is cleared.
- Reset all Activity filters and confirm the full transaction list returns.
- Open the Budget screen and edit the current month's budget, then confirm the changes remain on the same month after reopening the screen.
- In a timezone where the local month differs from UTC, confirm Home, chat, and the Budget screen all show and update the same month.
- Ask chat to view or update this month's budget and confirm the result matches the Budget screen.
