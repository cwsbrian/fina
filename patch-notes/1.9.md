# Fina 1.9

Date: 2026-07-14

## User-Facing Changes

- Added income and net cashflow throughout Fina.
  - Analysis now shows income, expenses, and net cashflow together.
  - Income transactions appear in Activity and transaction lists instead of being hidden.
  - Account transfers and other excluded transaction types remain excluded in both directions.
- Improved refund handling.
  - Refunds remain visible in the transaction list.
  - Matched refunds reduce the original expense instead of being counted as separate income.
- Added an Expense / Income selector to manual transaction entry.
  - Income entries use income categories and are included in cashflow totals correctly.

## Backend Changes

- Added direction-aware cashflow aggregation across Analysis, Budget, Chat, and Brief data.
- Applied transfer and excluded-transaction rules symmetrically to expenses and income.
- Added refund-to-expense matching and net expense calculations.
- Added persisted budget-impact and refund-link metadata with a production migration.

## Mobile Changes

- Added income, expense, and net cashflow presentation across Analysis, Activity, and Chat transaction cards.
- Updated transaction details and category selection for income and refunds.
- Added Expense / Income selection to the New transaction screen.

## Verification

- `pnpm nx run-many -t typecheck -p mobile api shared`
- Focused API tests for analysis, budget snapshots, cashflow, budget impact, manual transactions, and transaction listing.
- Mobile Activity pagination tests and changed-file ESLint checks.
