# Fina 1.8

Date: 2026-07-13

## User-Facing Changes

- Made manual transactions a first-class way to use Fina.
  - Home now leads new users to add spending without requiring a bank connection.
  - Transactions can be added naturally in Chat, with bank sync remaining optional.
  - Fina automatically uses learned merchant categories and asks for a category when it cannot determine one confidently.
  - Manual-entry prompts are hidden once transactions already exist.
- Added multi-select category filters to Activity.
  - Filters support regular categories and Uncategorized transactions.
  - The selection remains while navigating within the current app session and resets after a fresh app launch.
- Added Uncategorized spending to Budget totals and category details, including its transaction list.
- Improved category management and selection.
  - Workspace editors can create, rename, and delete categories.
  - The Chat category picker now opens above the transaction detail sheet, and Uncategorized stays at the end of the list.
- Improved transaction details by aligning account values consistently with the other fields.
- Made forecasts and Morning Briefs more relevant.
  - Forecasts now give current-month spending pace more weight and avoid treating historical overspending alone as a current daily problem.
  - Fixed or front-loaded categories such as Housing are no longer projected as if the same expense repeats every remaining day.
  - Daily briefs suppress unchanged forecast warnings and show them again after a meaningful change; Weekly briefs remain unaffected.

## Backend Changes

- Added Chat tooling and intent handling for one-time manual expenses, including learned merchant categorization and category follow-up.
- Added category filtering for split and uncategorized transactions to the transactions API.
- Added daily forecast-state persistence and meaningful-change detection for brief deduplication.
- Updated category forecast pace, scheduled-spend handling, and fixed-expense behavior.
- Included Uncategorized allocations in budget snapshots.

## Mobile Changes

- Added the Activity category filter sheet and filter-aware pagination.
- Updated Home and Chat empty states to prioritize manual entry and present bank connection as optional.
- Presented Chat category selection from the root modal layer so it is not obscured by the detail sheet or navigation.
- Updated category permissions, Budget drill-down behavior, and transaction detail alignment.
