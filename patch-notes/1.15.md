# Fina 1.15

Date: 2026-08-07

## App Store — What’s New

- Choose a workspace currency from More and see it consistently across transactions, budgets, goals, scheduled expenses, subscriptions, and chat.
- Chat now recognizes currencies in transaction requests and asks before changing the workspace currency.
- Morning Brief now follows the language used in your latest conversation.
- Improved currency symbols so amounts use compact labels such as `$`, `€`, `¥`, and `₩`.

## User-Facing Changes

- Workspace currency
  - Workspace owners can change the currency from More → Currency.
  - Changing the currency relabels existing workspace amounts without applying an exchange rate or changing their numeric values.
  - Transactions, budgets, goals, scheduled expenses, recurring subscriptions, analyses, Home summaries, and chat cards all use the active workspace currency.
- Currency-aware chat transactions
  - Messages such as `Antonino 4,50€ el 23 julio` are recognized as manual transaction requests with EUR and a localized decimal separator.
  - When the requested transaction currency differs from the workspace currency, Fina explains the impact and asks for confirmation before changing the workspace and recording the transaction.
  - Confirmed changes update the workspace currency and add the transaction together, avoiding partially applied results.
- Language-aware Morning Brief
  - Daily, weekly, and monthly briefs use the language of the user's latest natural-language chat message.
  - Merchant names, tool output, assistant messages, and financial data no longer influence the response language.
- Compact money labels
  - USD and CAD display as `$` instead of `US$` or a currency code.
  - JPY, EUR, GBP, and KRW display as `¥`, `€`, `£`, and `₩`.

## TestFlight — What to Test

- Open More → Currency as a workspace owner, change between CAD, USD, EUR, JPY, and KRW, and confirm the selection persists after reopening the app.
- Confirm amounts across Home, Activity, Budget, Goals, scheduled expenses, subscriptions, analysis screens, and chat cards use the selected symbol.
- Set a workspace to CAD, then ask chat `Antonino 4,50€ el 23 julio`; confirm Fina replies in Spanish and asks before changing the workspace to EUR.
- Cancel the confirmation and verify neither the workspace currency nor the transaction changes.
- Accept the confirmation and verify the workspace changes to EUR and the Antonino transaction is recorded as `€4.50` on July 23.
- Ask a Korean transaction question and confirm the response remains Korean after tool execution.
- Write the latest chat message in Spanish, Korean, or another language, then generate Morning Brief and confirm the brief follows that language.
- Switch between CAD and USD and confirm both use the compact `$` symbol rather than `CA$` or `US$`.

## Android Release Automation

- `pnpm release:android` builds the production AAB locally and then submits that artifact to the Google Play internal track.
- `pnpm release:android:aab` builds `dist/fina-android-latest.aab` locally without submitting it.
- `pnpm submit:android` submits the local `dist/fina-android-latest.aab` artifact to the internal track.
- `pnpm release:android:cloud` remains available for unattended EAS cloud build and auto-submit workflows.
- The first automated submission requires a Google Play Console service-account key to be configured in EAS Submit. Raw keys remain local or in EAS credentials and must never be committed.
