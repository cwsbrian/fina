# Fina v1.5

Date: 2026-07-02

## User-Facing Changes

- Added an answer share action in Chat.
  - Assistant replies now show a share icon beside the report icon.
  - Text-only replies and replies with `View detail` both keep the action row aligned with the message bubble.
  - The shared content includes only the visible assistant text, not hidden tool/card details.
- Improved chat issue reporting placement.
  - The report icon stays in the same action row as the answer action.
  - Structured details remain behind `View detail` so chat stays easier to scan.
- Morning brief summaries are more accurate for users with multiple workspaces.
  - Briefs now use the exact workspace name when describing each workspace.
  - Empty, inactive workspaces with no budget and no transactions are left out of the brief.
  - This prevents one workspace's budget or forecast from being described under another workspace's name.

## Backend Changes

- Hardened support email delivery.
  - Production Resend failures are no longer swallowed as successful sends.
  - Local/dev fallback behavior remains available for sandbox or unverified-domain testing.
  - Production email defaults now use `Fina <no-reply@buildingintent.com>`.
- Strengthened daily brief workspace context.
  - Added explicit `briefLabel` values for workspace-specific prompt context.
  - Updated brief prompt rules to avoid ambiguous labels like "your workspace" when multiple workspaces exist.

## Mobile Changes

- Added a chat answer action powered by the existing native share/clipboard helper.
- Updated the action icon and accessibility label to reflect Expo Go behavior:
  - Icon: `share-outline`
  - Label: `Share answer`
