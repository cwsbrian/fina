# Fina 1.7

Date: 2026-07-06

## User-Facing Changes

- Improved Chat budget forecast explanations.
  - Fina now uses the forecast values returned by its budget tools as-is.
  - It no longer invents unsupported reasoning such as "last month was $400, so this month will be $600" from timing patterns alone.
  - When asked for the basis, Fina explains the forecast from recent spending history plus money already spent or scheduled.
- Made Chat write cards easier to use.
  - Add/edit recurring expense forms now appear directly in the chat thread.
  - Goal forms also appear directly in the chat thread.
  - `View detail` remains for drill-down details instead of being required for simple write actions.

## Backend Changes

- Tightened the Chat system prompt around forward-looking budget answers.
  - Category projections must come from `compareSpendingVsBudget` / `projectMonthEnd` results.
  - The assistant must not create a higher projection or causal story from raw pace, early-month spending, or late-month habits unless the tool result supports it.

## Mobile Changes

- Updated chat block rendering so structured cards render inline in the message thread.
- Reused the existing form submission and intent handlers for inline recurring and goal forms.
- Kept detail navigation available for list/detail blocks such as categories, accounts, subscriptions, goals, transactions, and category review.
