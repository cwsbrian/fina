# Fina 1.12

Date: 2026-07-29

## App Store — What’s New

- Added a clearer cash-flow view: income stays visible, transfers stay out of spending, and refunds reduce the original expense.
- Stopped Morning Brief generation and delivery after an account returns to the Free plan.
- Added a prominent Home alert when a bank connection needs to be restored, with a direct path to Banks.
- Improved Pro conversations with one continuous chat per workspace and more context-aware Morning Briefs.
- Improved sign-in reliability, localized subscription pricing, and chat keyboard spacing.

## User-Facing Changes

- Cash flow
  - Income transactions remain visible in activity and cash-flow summaries.
  - Transfers and other non-spending movements stay excluded from spending.
  - Matched refunds reduce the original expense instead of appearing as income.
  - Unmatched refunds are clearly marked for review.
- Free plan
  - Chat, Goals, and Morning Brief now show an upgrade screen before an unavailable feature can be used.
  - Daily Brief generation, LLM usage, thread creation, and push delivery stop when the trial ends.
  - Linked Plaid items are removed after a downgrade while imported transaction history is preserved.
- Pro plan
  - Each workspace now has one continuous conversation instead of multiple selectable threads.
  - Morning Brief uses recent workspace conversation context and previous briefs to provide more relevant guidance.
  - Long conversations are trimmed to a recent context window and use a stable prompt prefix for provider caching.
- Plaid
  - Reconnecting a previously removed institution preserves transaction history without creating duplicates.
  - Billing-driven disconnects are distinguished from intentional disconnects.
  - Home displays a persistent reconnect notice that opens Banks directly.
  - The reconnect notice clears after the institution is successfully linked again.
- Billing
  - Plan prices come from StoreKit or Google Play and respect the customer’s storefront and currency.
- Reliability and polish
  - Sign-in sessions now use a longer sliding refresh window.
  - Removed the oversized keyboard gap in Chat.
